# Sistema de Controle de Estoque em Java

Projeto desenvolvido em Java com foco em Programação Orientada a Objetos e boas práticas.

## Funcionalidades
- Cadastro de produtos
- Listagem de produtos
- Controle de estoque
- Cálculo do valor total

## Tecnologias
- Java
- Console Application

## Como executar
- Abra no IntelliJ ou Eclipse
- Execute a classe Main
